# cut-lattice：切分多备选评测集

> 归属（Sheldon 11-25 定）：评测集、金标（含 L3 折线）、候选覆盖（A 层）由 **CV2** 维护；CV4 只负责从候选里挑切法（B、C 层）。

量「切字给多个备选、下游挑一条」这件事：候选够不够（A 层，CV2）、挑得对不对（B 层，CV4）、换了以后定字错不错（C 层，CV4）。schema 与三层指标的定义见 ai-team `domain/CV/A24/切分多备选-schema与benchmark-草案-2026-11-25.md`。

## 打分（score.py，2026-11-26）
`python cut-lattice/score.py --pred <产物根> [--books shiji,qtw] [--split tune|blind|all] [--against <另一产物根>] [--actual]`，产物根下按册放 `<vol>/row_segment/pNNNN.json`。
只依赖本目录：逐轨（main／夹注 a、b）合成预测切线，金标线（`page_ends` y 均值）在 0.15×金标线间距中位内有预测线算对；报线对数、列线全对（全对上且不多线）、字数对（格位数＝`gold_n`）、错列修回、好列保住。口径细节见文件头。
基线（cv dev 3698522＋史記判官，史記 42 全部 44 列）：线 789/874 → 开 `boundary_net` 808/874。

## 字段（items.jsonl 一行一列）
- `key`＝`book:vol:page:col`；`group` wrong（现役切错）／good（现役切对，对照）；`split` tune／blind。
- `lines[]`：金标切线，`track` main 或夹注 a／b，`between` 上下格号，`k` 切点序号，`page_ends` 原图坐标 raw_page_px@top-right 的［右端点, 左端点］，`y_col` 列图 y。
- `col_img_sha`：该页 column_warp 产物 sha256 前 16 位。对不上时（第二步重跑过）用 `page_ends` 经新 quad 重投回列图，不要直接用 `y_col`。
- `gold_n`／`pred_n`／`ref_n`：金标、现役、参校本的格数；`ref_ok` 参校本字数与金标一致（目前只有史記有配页表）。
- `review`：`status` 恒为 ok，`how` click（点过格）／page_ok（整屏全对）／fix-1125（v1.1 修正后确认），`has_jiazhu`。
- `since`：v1.1 起追加的行记版本号；v1 的行没有这一项。

## 规矩
- 盲测集只在方案定稿和上线前跑，不用来调参；样本少于约 20 列的错型只报数，不调参。
