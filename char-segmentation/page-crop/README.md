# page-crop —— 上游裁切吃掉最外列

## 这个分片量什么

s3 把页面裁窄时，最外一列的字**根本不在页图里**。网格照书级列距把列窗
算到页图之外，越出多少，就是那一列被吃掉多少。

来源：2026-08-25 用户在 vol01/18 col1 连标 7 个字位为「切错」。查下来
那一列的墨一路顶到页图右缘 x=1607（页宽 1608），而列窗算到 1629 ——
字的右半边不在图上，切分层再怎么改也变不出来。

## 为什么不需要人工标注

越界是**网格模型与页图尺寸的直接比较**，没有主观判断：

```
over_right = max(cell_right_x) - image_width
over_left  = -min(cell_left_x)
```

超过 `over_threshold_px`（8px，以下是网格拟合的正常毛刺）即记一页。
金标只记「当前哪些页越界、越了多少」，回归口径是：

- 没越界的页**不许**新越界；
- 已越界的页**不许**越得更多（+0.5px 以内算噪声）。

修好一页就从实测里消失，评测会打印「✔ 修好」，确认之后用 `--update`
重写金标。
