# 异体字组 U-Net 切分标注（2026-10-21，M7 形近字算法）

`variant/<组>/labels.jsonl`（组＝xu 叙敘、jiao 教敎、jue 絕絶）：每行 `{id, form, cut, orient, which, by, date, src}`。
`cut` 是 sheldon 在手机审查页上确认或修改过的一条折线（归一化坐标，原点左上，点为 [x,y]，h 按 x 排序、v 按 y 排序；`orient=v` 左右切）；
`which` 是用来区分两字的那一段（0＝上／左，1＝下／右）：叙敘看右部（又／攵）、教敎看左部、絕絶看右部。
`crops/<id 冒号换下划线>.png`：灰度字块，来自中心库殿本字形库的实例图，裁到墨迹外框（与 Step4 字块同口径）。
机器预填（自动缝或 U-Net）后人只改错的；点选结果存在审查页内，这里是落盘的一份。
