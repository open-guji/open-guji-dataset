# char-segmentation / book-columns —— 各书切分难列（按书分开）

## 这个子集在测什么

Step3（逐字切分）在**整列**上切对没有：每个字一格、小注按 a/b 半格，格线不落在字中间。
金标是人对着列图定下的整列格表（与中心库 manual-cells 钉子同一份），挂在**列图像素**上，
算法怎么改都还成立（只要 Step1–2 列图不变；列图随样本一起放在 `samples/`）。

**按书分开**（Sheldon 2026-11-20 定）：不同书的版式、字距、小注写法不一样，同一个错在甲书是常态、
在乙书是个例。每部书一个子目录、各自的 `items.jsonl`，分数分书报，不要混成一个数。

| 子目录 | 书 | 列数（有金标） | 来源 |
|---|---|---|---|
| [maijing](maijing) | 《脉经》内阁文库藏明翻宋何大任本，book 99k3i35yww，第 1 册 | 32（28） | 卷一 247 格待审逐列看图挑出的切分错 + 已放行的 38:10 |

## 金标定义

- `expected.cells`：整列有字的格，`{slot, sub, kind, x0, x1, y0, y1}`，列图像素、左上原点。
  `kind` 取 `char`／`jiazhu_a`／`jiazhu_b`；小注同一 `slot` 的 a 是右行（x 大）、b 是左行。空格不列。
- 判据是**字**：一格恰好框住一个字的全部笔画。**不算**错的：格框比字宽一些、留白多少（Step4 收墨会裁）。
- `expected.cells = null`（`gold: none_overlap`）：字上下交叠，任何水平格线都要切到一边，矩形格表达不了。
  这些列不打分，作为**开放问题**留着（要按笔画归属的算法才能做对）。
- `expected.category`：错的类型（A–G，见下表），按类分报。

| 类 | 是什么 | 《脉经》列数 |
|---|---|---|
| A | 大字被劈成小注 a/b（左右结构字中间白缝像小注分行） | 3 |
| B | 一对小注没劈开、并成一个大格（小注只有一两字、后接「一作」） | 3 |
| C | 上下字界线落在字中间（一字劈两格／两字并一格） | 13 |
| D | 列尾小注切错 | 6 |
| E | 版框线／书口被当成列或压进列里 | 3 |
| F | 职名列小字上下交叠（无金标） | 2 |
| G | 「生薑」草头与上字交叠（无金标） | 2 |

## 跑分

```bash
python char-segmentation/book-columns/score.py char-segmentation/book-columns/maijing/items.jsonl  预测.jsonl
```

预测每行 `{"id": …, "cells": [...]}`（同金标格式）。一格算对＝与金标格 1 对 1 配上且 IoU ≥ 0.75。
报列全对率（金标每格都配上、没有多余格）与格级 P/R/F1，按类分。不给预测文件时给 `input.baseline` 打分。

## 基线（出问题那一版，2026-11-20）

`input.baseline` 是 cv dev d84bf8d 的卷一包 `…-k2-yolo-cells` 里这一列实际用的切法（主切法或 YOLO 整列备选）：

| 类 | 列全对 | 格 F1 |
|---|---|---|
| A | 0/3 | 0.928 |
| B | 0/3 | 0.906 |
| C | 0/13 | 0.916 |
| D | 0/6 | 0.948 |
| E | 1/3 | 0.746 |
| **全部** | **1/28** | **0.915** |

E 的 1 列（45:11）只差格左边界（版框竖线压在列里），IoU 刚过线；看格的人会说它是错的，列全对对它不敏感。

## 样本文件

`samples/<册>-<页>-<列>/`：`column.png` 列图（算法输入，Step1–2 出的二值列图）、`gold.png` 金标叠框、`baseline.png` 基线叠框。
生成脚本：open-guji 项目文件 `maijing-seg01/dataset/build_book_columns.py`（在书工作区里跑，读钉子与旧产物包）。

## 加一部书

新建 `book-columns/<书名>/`，同样的 `items.jsonl` 信封；`id` 用 `<书名>:<册>:<页>:<列>`，`anchor.book` 写 `<book id>/<册>`。
不要把别的书的列塞进已有子目录。
