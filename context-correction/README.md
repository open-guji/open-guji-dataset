# context-correction —— 上下文纠正测试集

**一句话**：9 页 / 81 列 / 1,404 个槽位，每个槽位带**冻结的候选分布**与
参考整理本金标，用来量「语言模型能把 top-1 往上抬多少、又会改坏多少」。
格式说明见 [../doc/context-correction.md](../doc/context-correction.md)。

候选冻结在样本里，所以本集测的是**纠正层**，不是 OCR 层：上游 OCR 一换，
本集的数字依然可比。

## 空间有多大

| | |
|---|---|
| `baseline_top1`（冻结候选的首选）| **89.32%** (1254/1404) |
| `gold_in_candidates_rate` | 94.52% —— 剩下 5.48% 金标压根不在候选里，**重排碰不到** |
| `headroom` | **5.20%** —— 金标在候选里但不是首选，这是重排的全部空间 |

报增益时必须说清占了 headroom 的几成，否则「+2%」听着像小改进。

## 当前基线（2026-08-23，λ=0.65）

通用语料 = 殆知阁 史藏/诏令奏议+经世文编+政书+职官 500 万字（opencc 转繁）；
本书语料 = 《总目》整理本，**已挖掉测试页窗口 1,949 字**；两个语料对测试页
金标的 8-gram 泄漏率均为 **0.0**。

| 本书分量权重 | top1 | 增益 | 救回 | 改坏 | 有害翻转 | 字形层不可改写 |
|---|---|---|---|---|---|---|
| 0.00（纯通用）| 90.53% | +1.21% | 38 | 21 | 1.67% | 是 |
| 0.50 | 91.17% | +1.85% | 43 | 17 | 1.36% | 是 |
| 0.75 | 91.31% | +1.99% | 45 | 17 | 1.36% | 是 |
| **0.90** | **91.45%** | **+2.14%** | 45 | 15 | **1.20%** | 是 |
| 1.00（纯本书）| 91.03% | +1.71% | 41 | 17 | 1.36% | 是 |

**+2.14% 吃掉了 5.20% headroom 的 41%。** 混合优于纯通用（+0.93pp）也优于
纯本书（+0.43pp）——这是「通用低权重兜底 + 本书高权重加尖」的直接证据。

### 消融一：通用语料的**体裁**比体量重要

两组通用语料都是 500 万字，只换体裁（本书卷首是上谕公文）：

| 通用语料 | 纯通用 | 纯本书 | 混合（本书 0.9）|
|---|---|---|---|
| 诏令奏议 / 经世文编 / 政书 / 职官 | **+1.21%** | +1.71% | **+2.14%** |
| 儒藏 / 易藏（经解）| **+0.00%** | +1.71% | +1.64% |

经解语料对上谕页**一点收益都没有**，混合还略微拖后腿。别只问「语料够不够
大」，先问「体裁对不对得上」。

### 消融二：λ（OCR 项 vs LM 项的配比），本书权重固定 0.75

| λ | 增益 | 有害翻转 |
|---|---|---|
| 0.75 | +1.28% | 1.04% |
| 0.70 | +1.64% | 1.04% |
| 0.65 | +1.64% | 1.44% |
| 0.55（旧默认）| +1.14% | **2.39%** |
| 0.45 | +0.14% | 3.59% |
| 0.35 | **−1.07%** | 5.02% |

旧默认 0.55 给 LM 的话语权过大：有害翻转比 0.70 高一倍有余。`refine` 的
默认值已改为 **0.65**。λ 再往下走会直接转成净负——**语言模型压过字形证据
就开始编字**。

## 已知局限

见 `metadata.json` 的 `known_limitation`。最要紧的：

1. **上下文是理想值**（相邻列取金标），故增益是上界；
2. **1,404 个槽位撑不起细粒度调参**：权重 0.5~1.0 之间差 2~6 个样本，在噪声内。
   站得住的只有「混合 > 纯通用」和「λ 0.55→0.65~0.70 让有害翻转减半」这两条，
   后者跨多组权重一致复现；
3. **单册单体裁**，候选只来自 rapidocr 一个来源；
4. **簇级边缘化没在本集上量过**——book9 只有 10 页，96% 的簇是单例。
