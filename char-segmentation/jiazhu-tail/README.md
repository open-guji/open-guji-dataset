# char-segmentation / jiazhu-tail —— 夹注段端收编（奇数字末行 / 漏拆末行）

## 这个分片在测什么

双行小注的**段端**是单格判据的天然盲区（2026-08-26 用户 r10 反馈）：

- **奇数字**：最后一行只剩右半一个字（「江西巡撫採進本」的「撫」）。
  单格判据要求墨跨度 ≥0.75 列距，半列宽的单字永远量不出；
- **偶数末行也常漏**：两个小字合起来跨度不足，桥接又救不了段端
  （只有一侧邻格）。

段端收编拿**邻格的缝中心**当尺，分型看 **b 侧最大连通体**：

| b 侧最大 CC | 判定 | 动作 |
|---|---|---|
| ≥250px（真笔画，「一」实测 ~700+）| 漏拆行 | 正常拆 a/b |
| <250px（邻字残渣）且墨 ≥80% 在缝右、a 侧够窄 | 单字尾 | 只发 a 半 |
| 其余 | 正文 | 拒收 |

**分型不能拿墨占比**——瘦字与残渣的墨占比重叠。实测 vol02/4:5:20 末行
「一｜璉」的「一」只占 18% 墨，按比例分型会被当残渣压制、整个字被丢
（红线事故，已修）。

## 样本与口径

57 条 = 全书扫描「确认夹注段的下一格是普通 char」的全部候选。
46 单字尾（撫/督/政/大/占…）/ 8 整行 / 3 拒收（則/等/然，全尺寸正文）。
`label_origin=model_visual`：模型判定 + 接触表逐例目视核对（含 3 条拒收、
4 条上下文放大验证）。**定向富集**，不能读作夹注错误率。
