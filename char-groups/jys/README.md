# jys — 己 已 巳

**类型**：形近（near_form）。殿本这三字基本同形，封口与否刻工不守（confusable-context 考据：宋元刻本已混，清《四庫》本仍混）。
**只能按文意定**：干支/时辰 →「巳」（天干「己」）；虚词「已经/而已/已而」→「已」；反身「自己/以己意/治己」→「己」。
「已/巳」本是一字分化，「己」才是真正的另一个字。

**审查页**：https://claude.ai/artifact/29RYYYYqyawNSWgUpkmNnN（vol04 待审格全收 70 + vol05 core 随机 50，共 120 格；卡片 `../review/jys_cards.jsonl`）。

46 格强真值上：
- **整理本错 26/46**（vol04 14/27、vol05 12/19）——与 vol02/03 一致，整理本在这一族不可用；
- 库首位错 37/46；
- `ji_yi_si` 规则（vol05 有产物的 19 格）错 6/19；
- vol05 放行 3 格错 1：`vol05:112:9:7`「總爲易外之别傳而【巳】」，`split_ref` 放行「巳」，实为「已」（句末「而已」）。

**用户的判法（原话转述）**：
- **整理本几乎不用看**——整理时没有按文意整理。
- 要找常见词组：天干地支的匹配不用说；大部分是常见搭配「而已」，或按文意表示「已经做了什么事」→「已」。
- 「己」用在天干，或表示「自己」：后面常跟「意」「見」「說」之类（「以己意」「參以己見」「斷以己意」）。
- 处理法跟另外两组完全不同，应单开一道：词组/搭配规则 + 文意（大模型），不靠字形、不靠整理本。

本批里能直接看到的搭配（裁决 → 前后字）：「以【己】意」「參以【己】見」「斷以【己】意」「附以【己】意」「遷就【己】說」×多；「而【已】」「業【已】」「久【已】失傳」「易學【已】著錄」×多；
「康熙【己】未／丑」「順治【己】丑」「萬厯【己】丑」（干支）；「熙癸【巳】」（干支）。

## 已知难点

- 整理本在这一族不可信（尤其 vol02），所以「证人一致」弱真值这一族**不给**；基线的放行错只能在强真值上数。
- 「己未」「己丑」这类干支被「書_」「稱_」之类的前字表抢先判成「已」——上下文要看**后字**是否地支。
- 老人裁事件有过「按字形判」的污染（confusable-context v1 发现 4 条把「已经」义判成「巳」，已改回）；人裁里「看着像 X、读作 Y」取 Y。
- vol04 没有人裁，强真值全是看图（vision），30 格。
