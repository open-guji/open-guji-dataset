# confusable-context — 形近对上下文消歧

刻本里有几对字反复出现、字形层再准也难分：**入/人、日/曰、論/諭**、
而/面、遺/還、曾/會……用户 2026-08-26 提的问题是「这个时候要借助
上下文」，并指了两条路：n-gram 语言模型，和大模型直接读上下文。
这一集就是用来量这两条路到底行不行的。

## 题面

一题 = 一个待定字位。给出：

* 本列 OCR 转写（目标位挖成 `△`）
* 本列整理本参照（**同一位也挖成 `△`**）
* 前列、后列的文本
* 两个选项（该字所属形近对的两个成员）

二选一。不给字形候选、不给覆盖率——这一集单独量的是**纯上下文**的
判别力，字形信号混进去就说不清是谁的功劳。

## 三条防线（这一集最要紧的东西）

**一、金标只收人裁。** 人是看着字形定的，与 n-gram（在整理本上训练）、
与整理本对齐通道都无关，是唯一对各臂都中立的真值。自动进库的字多数
由 align（整理本）锚定，拿它当金标去考一个在同一语料上训练的 LM，
等于让考生带着答案进考场。

**二、参照文本也要挖空。** `align.char is None`（管线没锚上）**不等于**
整理本那一位是空的——实测 43 条难档里仍有 12 条参照文本直接写着答案。
两列按位等长对齐（实测 161/161），所以同一个下标挖两次。

**三、n-gram 臂必须报 heldout 口径。** 把所有测试列的整理本原文从训练
语料里剔掉再训。不剔（`--mode book`）在送分档上是 **100%**——那是把
原文背下来了，不是学会了。两个口径的落差就是记忆的贡献。

## 分档

| 档 | n | 含义 |
|---|---|---|
| `easy_ref_gives_answer` | 123 | 整理本该位给的就是金标。生产里 align 通道本来就能锚定，属送分档；但挖空后仍是合格考题，而且类别更均衡（人/入 20 题多数类才 50%）|
| `hard_ref_silent` | 32 | 整理本该位没给或给了别的字（脱字/异文/未覆盖）。上下文必须自己扛 |

## 首轮结果（2026-08-26，剔除已/巳，n=142）

| 臂 | 真难档 | 送分档 | 合计 |
|---|---|---|---|
| 多数类基线 | 96.3% | 68.7% | 73.9% |
| 字形层 top-1 | 70.4% | 62.6% | 64.1% |
| OCR | 55.6% | 66.1% | 64.1% |
| **n-gram(3) heldout** | 92.6% | 97.4% | **96.5%** |
| n-gram(3) 只用通用语料 | 85.2% | 93.0% | 91.5% |
| **大模型（盲测）** | 96.3% | 100.0% | **99.3%** |

两条路都成立，且都远超字形与 OCR。逐对明细见 `baseline_r1.json`。

## ⚠ 已/巳 治不了，报总分时必须剔除

这一对是**字形层问题，不是语义问题**。实锤：

* `[016]` 「實在流傳**巳**久」 金标 巳
* `[059]` 「實在流傳**已**少」 金标 已

语境同构而金标相反——同一个词，刻工有时刻巳、有时刻已。所有臂在这一对
上都卡在 62~69%，谁都没超过多数类基线。`config/variants/variants.json`
里 `已 → 巳` 已登记为异体（hydzd/yitizi），**语义层本来就归并了**，
剩下的只是「刻的是哪个形」，那是字形层与人的活。

任何新形近对进表之前都该先过这一问：它是语义可分的，还是异体同词的？
后者送进上下文通道是白费。

## 复现

```bash
cd open-guji-cv
# n-gram 臂（三种语料口径）
PYTHONPATH=. python scripts/eval_confusable_lm.py <dataset>/confusable-context/cases.json \
    --book-corpus corpus/zongmu_wuyingdian_reference.txt \
    --general-corpus corpus/external/daizhige_zhaoling.txt \
    --mode heldout --out /tmp/lm.json
# 各臂对答案（答案文件到这一步才读——盲测的意义全在先后顺序上）
PYTHONPATH=. python scripts/score_confusable.py <dataset>/confusable-context/answer_key.json \
    --cases <dataset>/confusable-context/cases.json --lm /tmp/lm.json
```

重建题面（队列增长后扩集）：`scripts/build_confusable_set.py output/vol01`，
盲测题面导出：`scripts/export_confusable_prompt.py`。
