# ref-mismatch —— 人裁字 ≠ 整理本字

## 这个分片是什么
定字审阅时，人按**图上刻的字**录入，与整理本（align_ref）对位字**不同**的格。
50 条（vol02，2026-10-01 一次审阅）：巳→已 19、䝉→𫎇 11、已→己 5、巳→己 4、變→𠮓 2、
日→曰 2、人→入 2，另 兒/迥/出/府 各 1。

vol03 追加 37 条（2026-10-05 收尾导出；已 14、己 5+2、傳/傅、釆/采、變→𠮓 等；排除缓存曾错位的 p66、p70、p76、p102 页格）。

⚠️ **不等于整理本错**：多为异体、形近、避讳、通假；整理本也可能是对的而刻本确实不同。
金标说的是「这一格刻的是什么字」，不是「整理本该改成什么」。

整理本占位符「〓」（缺字）的 28 格**不收**——那是整理本没有字，不是两个字不同。

## 字段
- `expected.char`：人录的字（刻本字）；`expected.ref_char`：整理本对位字
- `input.patch`：本分片 `patches/` 下的字块图；`input.align_op`：对位操作（equal/replace/None）
- `label_origin=human`，`stratum=human_vs_ref`（**不是随机抽样**，是人裁时遇到的差异，不能估总体比例）

## 怎么用
评测识别 / 上下文裁决时，看系统在这些格上是出「刻本字」还是被整理本带偏（尤其 己/已/巳、日/曰、入/人）。
目前没有专门评测脚本。
