# page-type —— 页型判别

## 测什么

**这一页该不该套刻本网格，套哪种。**

管线原先完全没有页型判断：profile 说每半页 9 列，就一律按 9 列切。封面、
书签、空白页照套，结果是纯垃圾——

- `vol01/2`（书签页，整页只有一条书名）→ 切成 **126 个块**，`bad_seg` 94%；
- `vol01/158`（近空白页，只有一列「春秋類一」）→ 格高锁到 **37.8px**
  （真值 114），切出 **0 个字**。

## 七种页型 → 三种网格策略

> 2026-10-25：`blank`（空白页）并入 `body`——空白页是正文的一种，处理方式与字少的正文页相同；金标里不再有 `blank` 键，空白用 `last_text_col = 0` 表示（见下「字写到第几列」）。

判别的落点不是文学分类，而是网格该怎么用：

| 策略 | 页型 | 为什么 |
|---|---|---|
| `skip` 不套网格 | `cover` 封面 · `label` 书签 · `colophon` 牌记 | 没有正文栏格，任何列拟合都是无中生有 |
| `custom` 换列数 | `edict` 上諭表文 | 字大列宽，列数少于正文 |
| `standard` 现有网格 | `body` 正文 · `roster` 职名 · `toc` 目录 | 三者共用 9 列刚性网格；它们的差别是**列内字距**，由 [column-layout](../column-layout) 那一层判，不在这里重复 |

| 页型 | 缩略图上的样子 | 本书页数 |
|---|---|---|
| `cover` | 页中一个双线大框，框内大字书名，无界行 | 10 |
| `label` | 页侧一条窄长框（书签），其余整页留白 | 7 |
| `colophon` | 有界行，仅一角有一个小框、框内大字 | 1 |
| `edict` | 有界行/版框，字明显大、列数少于正文 | 1 |
| `body` | 九列正文，字多字少、整页空白（`last_text_col=0`）都算 | 350（含 vol03–10 抽样 53 页，其中 vol01 的 3 页原为 blank） |
| `roster` | 九列，职名，字距拉开 | 44 |
| `toc` | 九列，目录，列上部有字下部空 | 47 |
| `uncertain` | 页型过渡处人工也判不准 → 评测跳过 | 0（现行金标已无此类） |

**vol01–02 的 394 页是全覆盖，vol03–10 是抽样 66 页**（`stratum`/`stratum_weight` 区分，批次 `vol03-10-2026-10-25`）。上表页数含抽样；vol01–02 的占比才是真实分布：
非正文页只占 2.0%，但它们贡献的是纯垃圾输出。

## 两个方向的错误代价完全不对称

- 该跳过却切了 → 产出一页垃圾，可被 `bad_seg` 等事后标记；
- 该切却跳过了 → **整页真数据丢失**，下游连「这里有东西」都不知道。

所以：主指标是 **`lost_rate`（误跳过正文页的比例）**，零容忍；分类器判不准
时**默认走网格**；阈值全部按「正文类页的极值」留一倍余量定，不是拟合出来的。

## 金标怎么来的

把全书渲染成缩略图接触表逐页目视判读。刻本页型在缩略图尺度就能认出来
（封面是页中一个大框、书签是页侧窄长框、空白页只有界行、牌记是一角一个
小框），不需要看清字。

**不用转写文本定页型**：转写依赖切分，拿它判页型是循环论证；且非正文页的
转写质量最差（封面页的转写基本是乱码），最需要判别的地方恰好最不可信。

标注按**区间**记（刻本同类页成段出现），表在
`open-guji-cv/scripts/build_pagetype_dataset.py` 的 `LABELS`。

```bash
cd open-guji-cv
python scripts/eval_pagetype.py ../open-guji-dataset/page-type
```

## 字写到第几列（2026-10-25 起，只进金标）

稀疏正文页（只有一两列字）和空白页长得很像，管线内部要能分清，但处理方式相同。九列格子页的 `expected` 里与 `page_type` 并列有四个字段（只给有完整九列格子的 body／toc／roster 页，cover／label／colophon 没有）：

| 字段 | 含义 |
|---|---|
| `last_text_col` | 0–9。九列半叶**从右数起**（1＝最右列）有字的最远一列；0＝整页无字 |
| `text_col_count` | 有字的列数（中间可有空列，不等于 `last_text_col`） |
| `col_ink` | 长度 9，各列「列带」（距两侧列线各 22%，避开框线）墨量百分比，右起 |
| `weak_cols` | 墨量 1.0–2.0% 的列号：不算有字，留人工复核 |

有字阈值 2.0%。1.0–2.0% 多为边缘列磨损或框线残留，空白页最高约 1.3%，所以阈值不降到 1.0%。这些字段是 **机器测量**（`open-guji-cv` 的九列格子探测＋列带墨量），不是逐字目视，不进评测主指标。**完整九列格子（10 条竖线）＝正文**是页型判据（`border_detect_gate` 的 `_full_grid`，cv#560）。评测读金标时略过不认识的键（cv#565）。封面、题签只有 3–6 条竖线，判据不会把它们当正文。印章、反色带落在列带里会抬高墨量，字段只表示「有墨」。

## 已知局限：牌记与上諭没有判据

**不是忘了，是证据不足以立规则。** 全书各只有 1 例，而它们的结构量与最
稀疏的目录页重叠：

| 页 | 类别 | `x_cover` | `n_glyph` |
|---|---|---|---|
| vol01/205 | colophon | 0.496 | 90 |
| vol01/182 | toc | 0.616 | **90** |
| vol01/61 | toc | **0.265** | 60 |

硬立一条规则去抓 205，就会把 61 这样的稀疏目录页一起跳过——那是丢真数据，
比多切一页废页严重得多。要解决得先攒够样本。

`edict` 的正解也不是「跳过」而是「用不同列数」，属于列数自适应问题，不是
页型闸门能解决的。
