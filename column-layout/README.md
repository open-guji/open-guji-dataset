# column-layout —— 行列识别（列型判别）

## 测什么

**逐列**判断这一列是刚性排布还是弹性排布：

| 列型 | 定义 | 典型 |
|---|---|---|
| `rigid` | 字距 = 1×格高 | 正文密排；目录页「卷一百四十八　集部一」（字少但字距仍是 1×）|
| `elastic` | 字距 ≠ 1×格高 | 职名页官衔拉开 ~3.5×；长标题压缩 ~0.5× |
| `blank` | 整列无字 | 由墨量客观判定，不进分类指标 |
| `uncertain` | 人工也判不准 | 题名页大字、抬头列字太少；评测**跳过** |

判据是**字距**，不是字数，也不是相位：

- 目录页一列只有 6 个字、后面全空 → 仍是 `rigid`；
- 抬头列（「上」「朝」被抬到格线之上）整体相位偏移但字距未变 → 仍是 `rigid`。
  相位偏移是另一个更易修正的问题，混进列型会让标签失去指导意义。

## 为什么必须做到列级

实测武英殿本两册 394 页：**164 页是混合页**（同页既有刚性列又有弹性列），
211 页全刚性，19 页全弹性。页级标签表达不了混合页。

而横向是刚性的——职名页与正文页的列间距变异系数同为 1.4%~2.4%：

```
vol01/107  职名页   周期 179.8px   CV=0.020
vol01/127  职名页   周期 182.8px   CV=0.014
vol02/18   正文页   周期 185.8px   CV=0.019
vol02/179  正文页   周期 183.0px   CV=0.024
```

所以弹性只发生在**纵向**，输出格式据此分两层（见
`open_guji_cv/clustering/layout_spec.py`）。

## 跑分

```bash
cd open-guji-cv
python scripts/eval_layout.py ../open-guji-dataset/column-layout/samples
```

主指标是 **elastic 的 F1**，不是准确率——elastic 占 36%，全判 rigid 也有
64% 准确率却毫无用处。报告**按页型分层**：正文页占语料约 80%，不能回归；
职名/目录页才是增益来源，混在一起平均会互相掩盖。

## 基线

| | 总体 F1 | body | toc | roster | edict |
|---|---|---|---|---|---|
| v0 隐式回退（只看组件间距） | 0.77 | 96.3% | **58.7%** | 82.1% | 85.7% |
| v1 显式判别（占位形态） | **0.84** | 100% | **92.1%** | 76.4% | 100% |

v1 页级二折交叉验证 **F1 0.837 ± 0.072**（全量调参的 0.873 乐观约 0.036）。
列数两版都是 36/36 全对。

### 各候选特征的判别力（本数据集 291 列实测 AUC）

```
n_comps        0.952      mid_frac       0.860
run_med(反向)  0.913      gap_int_dev    0.755
iso_frac       0.912      straddle       0.623
                          max_gap        0.612   ← v0 用的就是它
字号特征       ≈0.50（无效）
```

v0 只看「间距是否够大」，而目录页与职名页**都是**字少、间距大——所以分不开。
真正的区分维度是**占位形态**：

```
             连续占位段长   半格比例
  正文密排        ~20        0.05
  目录稀疏         ~4        0.05     「卷一百四十八」六个字连着
  职名拉开          1        0.18     逐格孤立
```

目录的字**连续成段**，职名的字**逐格孤立**——这是间距判据看不见的。

### 尚未解决

压缩型弹性列（长官衔挤进同列）占位是满格，与密排正文同形——占位类特征
区分不了「一格一字」与「一格两字」。106 列职名金标里漏判 25 列，其中
`vol01/90` 一页就占 8 列（该页首列「經筵日講起居注官／太子太保領侍衛內
大臣／武英殿大學士臣阿桂」27 字挤进 22 格）。逐字读过原图确认金标无误，
是特征维度不够，需要能直接测字距的特征。

## 标注方法

人工目视：把**纯刚性格线**（书级 `cell_h` + 页相位）叠在列上，看红线是落在
字与字之间（rigid），还是穿字而过／字数与格数对不上（elastic）。

标注表在 `open-guji-cv/scripts/build_layout_dataset.py` 的 `PAGE_LABELS`，
改标注只改那张表，重跑脚本即可。空列由墨量自动判定，不算人工判断。

> 构建过程中修正过 3 页自标错误（vol01/193、vol01/196 实为目录页而非正文页，
> vol02/1 是题名页）。修正后 body 从 90.4% 升到 96.3%、toc 从 62.2% 降到
> 58.7%——**错误的标签会同时高估和低估算法**，这是复核值得做的直接证据。
